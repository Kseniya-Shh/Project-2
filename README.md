# Project-2
Задача: работа над спецификацией требований.
Необходимо обновить спецификацию: добавить функциональные требования для новых функций приложения, описать требования к ним, а так же обновить диаграмму UML Use Case; добавить новые табличные варианты использования. 
Дополнительно, необходимо заполнить другие разделы спецификации, а именно атрибуты качества, бизнес-правила и глоссарий.
